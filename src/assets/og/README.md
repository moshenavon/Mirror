# Link preview assets

Used by `src/app/r/[token]/opengraph-image.tsx` to draw the image shown when a
public link is shared (WhatsApp, Slack…).

- `Rubik-*.ttf` – Rubik by Hubert & Fischer, SIL Open Font License 1.1 (Google Fonts).
- `emoji-*.png` – Noto Emoji by Google, Apache License 2.0, resized to 160px.
- `logo.png` – the Mirror logo (same as `public/icon-512.png`).

# Mirror – אפיון מערכת

> פלטפורמה לאיסוף תובנות צוות לאורך זמן והצגתן בצורה מסודרת בפגישת רטרו.

## 1. מטרה

חברי צוות מתעדים לאורך התקופה (שבועיים / חודש) מחשבות, חוויות ותובנות לפי קטגוריות ("שדות")
שהוגדרו מראש ע"י מנהלי הצוות. בפגישת הרטרו מנהל הצוות פותח את "מסך התובנות", בוחר טווח תאריכים,
ועובר שדה-אחר-שדה ודיווח-אחר-דיווח, כשכל דיווח מוצג עם התמונה והשם של המדווח.

## 2. מונחים

| מונח | הסבר |
|------|------|
| **צוות (Team)** | קבוצה מנוהלת. כל משתמש מחובר יכול ליצור צוות. |
| **חבר צוות (Member)** | כתובת מייל של חשבון Google שהוגדרה כשייכת לצוות. |
| **מנהל צוות (Admin)** | חבר צוות עם הרשאות ניהול. יוצר הצוות הוא מנהל אוטומטית. |
| **שדה (Field)** | קטגוריית דיווח (למשל "ממה אני שמח"), עם אימוג'י, כותרת, טקסט עזר ומיקום בסדר. |
| **דיווח (Entry)** | תובנה/חוויה שחבר צוות כתב עבור שדה מסוים. |
| **מסך תובנות (Insights)** | מצגת הדיווחים לפי טווח תאריכים, מסודרת לפי סדר השדות. |

## 3. סטאק טכנולוגי

- **Frontend + Backend:** Next.js (App Router, TypeScript, Server Components + Server Actions), Tailwind CSS.
- **אירוח:** Vercel.
- **מסד נתונים:** Supabase Postgres, עם Row Level Security (RLS) כשכבת ההרשאות המרכזית.
- **הזדהות:** Google OAuth 2.0 ישירות מול Google Cloud Console (Authorization Code + PKCE). השרת מאמת את ה-ID Token של Google,
  מנפיק cookie חתום משלו, ובכל בקשה למסד הנתונים חותם JWT קצר-מועד שמזין את ה-RLS. Supabase Auth אינו בשימוש.
- **בדיקות:** Vitest + React Testing Library (unit + component), בדיקות RLS ב-SQL מול מסד הנתונים.
- **שפה:** ממשק בעברית, RTL, מותאם מובייל ודסקטופ.

## 4. משתמשים והרשאות

### 4.1 הזדהות
- כניסה באמצעות Google בלבד.
- זיהוי השיוך לצוות מתבצע לפי כתובת המייל של חשבון Google (case-insensitive).
- בכניסה הראשונה נוצר פרופיל (שם + תמונה מ-Google) ומתעדכן בכל כניסה.

### 4.2 מטריצת הרשאות

| פעולה | משתמש מחובר | חבר צוות | מנהל צוות |
|-------|:---:|:---:|:---:|
| יצירת צוות חדש | ✅ | ✅ | ✅ |
| צפייה בצוות ובשדות | – | ✅ | ✅ |
| שליחת דיווח | – | ✅ | ✅ |
| צפייה/עריכה/מחיקה בדיווחים **שלי** | – | ✅ | ✅ |
| מסך תובנות | – | ⚙️ רק אם הוגדר "כל חברי הצוות" | ✅ |
| עריכת פרטי צוות והגדרות | – | – | ✅ |
| ניהול שדות (הוספה/עריכה/סידור/השבתה) | – | – | ✅ |
| ניהול חברים (הוספה/הסרה/מינוי מנהל) | – | – | ✅ |
| מחיקת צוות | – | – | ✅ |

- ברירת מחדל: `insights_visibility = 'admins'`. מנהל יכול לשנות ל-`'members'`.
- לא ניתן להסיר/להוריד את המנהל האחרון בצוות (נאכף במסד הנתונים).
- כל ההרשאות נאכפות ברמת מסד הנתונים (RLS + פונקציות `security definer`), ולא רק ב-UI.

## 5. מודל נתונים

```
profiles        (id PK→auth.users, email, full_name, avatar_url, created_at, updated_at)
teams           (id, name, description, insights_visibility['admins'|'members'], created_by, created_at, updated_at)
team_members    (id, team_id→teams, email [lowercase], role['admin'|'member'], added_by, created_at)  UNIQUE(team_id,email)
team_fields     (id, team_id→teams, label, emoji, placeholder, position, is_active, created_at, updated_at)
entries         (id, team_id→teams, field_id→team_fields [אותו צוות], author_id→profiles, content, created_at, updated_at)
```

- `team_members` מבוסס מייל ולא user_id – כך שאפשר לצרף אנשים שעדיין לא התחברו מעולם.
- שדה שיש לו דיווחים לא נמחק אלא מושבת (`is_active=false`) כדי לשמור היסטוריה.
- `entries.content`: 1–2000 תווים.
- `team_id`, `author_id`, `created_at` של דיווח אינם ניתנים לשינוי (נאכף בטריגר).

### 5.1 פונקציות מסד נתונים (RPC)
| פונקציה | תיאור |
|---------|-------|
| `create_team(name, description)` | יוצר צוות, מוסיף את היוצר כמנהל, ויוצר 4 שדות ברירת מחדל. |
| `reorder_fields(team_id, field_ids[])` | קובע סדר שדות (מנהל בלבד). |
| `get_insights(team_id, from, to)` | מחזיר דיווחים בטווח עם שם ותמונת המדווח, ממוינים לפי סדר שדה ואז זמן יצירה. בודק הרשאת צפייה. |
| `my_teams()` | הצוותים שלי + התפקיד שלי בכל צוות. |
| `get_achievements(team_id)` | מספר הדיווחים (לא אנונימיים) של כל חבר צוות + שם ותמונה. לחברי הצוות בלבד. |

### 5.2 שדות ברירת מחדל לצוות חדש
1. 😄 **ממה אני שמח** – "מה עשה לי טוב לאחרונה?"
2. 😢 **ממה הייתי עצוב** – "מה הציק לי או העציב אותי?"
3. 💡 **מה למדתי** – "תובנה או לקח מיוחד"
4. ⚠️ **דבר שצריך להימנע ממנו** – "משהו גרוע שקורה בצוות ושכדאי לעצור"

## 6. מסכים

### 6.1 כניסה – `/login`
כפתור "התחברות עם Google". לאחר הזדהות → חזרה לעמוד שממנו הגיע המשתמש (או `/`).

### 6.2 הצוותים שלי – `/`
- רשימת הצוותים שהמייל שלי משויך אליהם, כולל תג "מנהל".
- כפתור "צור צוות חדש".
- אם אין צוותים: הסבר שצריך לבקש ממנהל צוות להוסיף את המייל, או ליצור צוות.

### 6.3 יצירת צוות – `/teams/new`
שם (חובה, עד 80 תווים) + תיאור (אופציונלי). לאחר יצירה → מסך הגדרות הצוות.

### 6.4 מסך דיווח – `/teams/[teamId]`
- כותרת: שם הצוות.
- רשת **כפתורים גדולים** – אחד לכל שדה פעיל, לפי סדר השדות: אימוג'י גדול + כותרת בפונט גדול.
- לחיצה על כפתור → חלון (dialog) עם תיבת טקסט (placeholder = טקסט העזר של השדה), מונה תווים, "שלח" ו"ביטול".
- לאחר שליחה: הודעת הצלחה, החלון נסגר.
- קישורים: "ההיסטוריה שלי", "מסך תובנות" (אם מורשה), "הגדרות" (מנהל).

### 6.5 ההיסטוריה שלי – `/teams/[teamId]/history`
- רשימת הדיווחים שלי, מהחדש לישן: אימוג'י + שם השדה, תאריך, תוכן.
- סינון לפי שדה.
- עריכה inline (תוכן + אפשרות להעביר לשדה אחר) ושמירה; מחיקה עם אישור.

### 6.6 מסך תובנות – `/teams/[teamId]/insights`
- בחירת טווח תאריכים: ברירת מחדל **14 יום אחורה עד היום**; קיצורי דרך: שבוע / שבועיים / חודש.
- סיכום: מספר דיווחים לכל שדה בטווח.
- "התחל רטרו" → מצב מצגת:
  - הדיווחים מסודרים לפי **סדר השדות** שנקבע בהגדרות, ובתוך כל שדה לפי זמן יצירה.
  - כל שקף: כותרת השדה (אימוג'י + שם), תמונת המדווח, שם המדווח, תוכן הדיווח, תאריך.
  - "המשך" / "הקודם", מקשי חיצים, מחוון התקדמות ("3 מתוך 7 • ממה אני שמח").
  - בסיום שדה → מסך מעבר "סיימנו את ___ – הבא: ___".
  - אפשרות לבחור שדה ולקפוץ אליו ישירות.
  - בסיום כל השדות → מסך "סיום הרטרו".
- שדות ללא דיווחים בטווח מדולגים.

### 6.7 הגדרות צוות – `/teams/[teamId]/settings` (מנהלים)
- **פרטים:** שם, תיאור.
- **הרשאת תובנות:** מנהלים בלבד / כל חברי הצוות.
- **שדות:** הוספה, עריכה (אימוג'י, כותרת, טקסט עזר), הזזה למעלה/למטה, השבתה/הפעלה, מחיקה (רק אם אין דיווחים).
- **חברים:** הוספת מיילים (אחד או רבים, מופרדים בפסיק/רווח/שורה), שינוי תפקיד, הסרה. מוצג שם ותמונה למי שכבר התחבר.
- **אזור מסוכן:** מחיקת הצוות (אישור ע"י הקלדת שם הצוות).

## 6.8 שליחה אנונימית
- בחלון הדיווח יש תיבת סימון "שליחה אנונימית 🎭".
- דיווח אנונימי נשמר **ללא `author_id`** – אין במסד הנתונים שום שיוך למשתמש.
- נשמרים: צוות, שדה, תוכן, ו**תאריך בלבד** (ללא שעה מדויקת, כדי להקשות על הצלבה עם לוגים).
- דיווח אנונימי לא מופיע בהיסטוריה של המשתמש ולא ניתן לעריכה/מחיקה ע"י השולח.
- במסך התובנות מוצג כ"אנונימי" עם אווטאר 🎭.

## 6.9 קישור ציבורי (ללא הזדהות)
- מנהל צוות יכול להפעיל בהגדרות "מילוי ללא הזדהות". נוצר קישור `/r/<token>` עם טוקן אקראי ארוך.
- מי שמחזיק בקישור רואה את כפתורי השדות הפעילים ויכול לשלוח דיווח – תמיד אנונימי.
- המנהל יכול לבטל את הקישור או להחליף אותו (הקישור הקודם מפסיק לעבוד).
- הטוקן גלוי למנהלים בלבד.

## 6.10 מיתוג ואנימציות

  ניתן לבחור מהם בהגדרות השדה (או להקליד כל אימוג'י אחר – יוצג עם אנימציית CSS).
- אנימציות: כניסה מדורגת של רכיבים, ריחוף ולחיצה בכפתורים, חלון דיווח קפיצי, קונפטי בשליחה ובסיום רטרו,
  מעברי שקפים במצגת. מכבד `prefers-reduced-motion`.

## 6.11 מסך הישגים – `/teams/[teamId]/achievements`
מטרה: לדרבן את חברי הצוות לדווח. פתוח לכל חברי הצוות.
- **מפה אנכית** שמתחילה למטה ("נקודת ההתחלה") ומטפסת למעלה. דרך מתפתלת מחברת בין התחנות.
- כל חבר צוות מוצג (תמונת פרופיל + שם פרטי + מספר הדיווחים) בתחנה שמתאימה לכמות הדיווחים שלו.
  טבעת סביב התמונה מראה את ההתקדמות לדרגה הבאה. מי שעוד לא התחבר מוצג עם ראשי תיבות ו-0 דיווחים.
- הדרגות (מלמטה למעלה):

  | דיווחים | דרגה |
  |:---:|---|
  | 0 | 🥚 ביצת הזינוק |
  | 10 | 🐣 גוזל המשוב |
  | 20 | 🕵️ בלש התובנות |
  | 50 | 🚀 טייס הרטרו |
  | 100 | 👑 מלך הדיווחים |

- כרטיס "הדרגה שלי": הדרגה הנוכחית, פס התקדמות, "עוד X דיווחים ל___", כפתור "לדווח עכשיו" וסך הדיווחים של הצוות.
- כשמשתמש מגיע לדרגה חדשה (לעומת הביקור הקודם באותו דפדפן): הודעת "עלית דרגה!" וקונפטי.
- דיווחים **אנונימיים לא נספרים** (אין להם מחבר).
- הנתונים מגיעים מ-`get_achievements(team_id)`: רק ספירות לכל חבר (בלי תוכן), לכל חבר צוות, גם כשמסך התובנות מוגבל למנהלים.
- הדרגות מוגדרות במקום אחד (`src/lib/achievements.ts`) – קל להוסיף דרגות או לשנות ספים.

## 7. דרישות לא-פונקציונליות
- אבטחה: RLS על כל הטבלאות; שום מפתח סודי בצד לקוח (רק publishable/anon key).
- ביצועים: אינדקסים על `entries(team_id, created_at)`, `team_members(email)`.
- נגישות: כפתורים עם `aria-label`, ניווט מקלדת במצגת, ניגודיות טובה.
- רספונסיביות: מסך הדיווח נוח לשימוש בטלפון.
